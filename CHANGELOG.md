# Changelog

## [1.1.0] - 2026-08-01

### Changed

- Replaced the private `Bag.CAPACITY` patch with the public
  `constants.bagSize` mod API introduced in Gen1Recomp v0.1.50.
- Removed the `engine_internals` permission.
- Added GitHub release update metadata.

## [1.0.0] - 2026-08-01

### Added

- Expanded bag capacity to 255 distinct item slots.
- Synchronized the public `bagSize` constant with the runtime capacity.
